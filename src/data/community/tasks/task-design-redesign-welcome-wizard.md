### Task Description & Details

* **Summary / Description:** 
  Redesign the current welcome app interface to closely mirror an Apple-style setup wizard. The goal is to provide a sleek, polished onboarding experience that guides users through a multi-step introduction or overview of the system's core capabilities.
* **Scope / Deliverables:** 
  * Build the Apple-inspired wizard UI shell (modal or full-screen setup flow with clean typography, card layouts, and smooth transition steps).
  * Implement an interactive feature showcase or list highlighting the following components:
    * Session Restore
    * Sayri — AI Assistant
    * Finder
    * 55 Cloud Providers
    * Recovery System
    * PKM
    * App Store
    * Spotlight
    * Keyboard Remap
    * Window Mode
    * Live Wallpapers
  * Integrate the new welcome app component within the existing React / TanStack Start structure.
* **Notes / Edge Cases:** 
  * Ensure the design tokens, spacing, and styling align with clean, Apple-inspired interface aesthetics.
  * Handle responsive layout behavior smoothly across different window sizes or full-screen modes.
  * Provide a clear path to dismiss or complete the wizard flow (e.g., "Get Started" or "Skip" actions).
