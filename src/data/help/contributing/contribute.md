We are delighted that you are interested in contributing to Pulsar OS.

## Before starting

- We recommend you visit our [Discord server](https://link.inled.es/discord) or any other chat platform we have and say hello.
- If you have any questions, the Discord server is the right place.
- If you are a developer, take a look at [the project board](https://github.com/orgs/Inled-Pulsar-OS/projects/1).

## Ways to collaborate

Whether you want to make a proposal, change anything, solve errors or propose improvements (these last two things interest us a lot), go ahead. We recommend that you talk to us through Discord before solving an error.

We are delighted that you collaborate in different ways.

- **Implementing features you want**: If you want some feature, first ask on the discord if its suitable and then you can implement it and make a PR
- **Perform tasks marked for the community**: We leave tasks marked for the community, we are preparing so that they can be announced on the discord. You simply assign it to yourself and start working on it.
- **Testing and error reporting**: Try Pulsar OS or use it daily and report errors or their solutions.  

## Steps to implement feature   
- Install the necessary dependencies
- If you have asked in the Discord and there is no problem, go ahead.
- Use native languages ​​for desktop and web applications for the page.
- Try the feature in Pulsar OS
- Make a PR on the PKG repo.

### The PR must contain
- PKG repo format: DEBIAN/folder and PKGBUILD
- Be prepared to be uploaded to the remote repo.
